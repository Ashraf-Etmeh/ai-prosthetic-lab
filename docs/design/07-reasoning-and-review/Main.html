The reasoning pathway and its guardrails

Six steps from the case to the documented outcome. Each step says what it produces and what stops it from overstepping.

المسار المستهدف
01 · بيانات الحالة
Case dataCoded fields with how each was measured; free text stays in the clinic.Guard: no identifiers
02 · تحليل المعلومات
Information analysisWhat is missing, and the passages each topic finds in the library.Guard: local search only
03 · الاستدلال المتخصص
Specialised reasoningDomain rules from the clinic, then a language model summarising the passages.Guard: quote checked word for word
04 · توصيات مساعدة
Assistive outputGaps, options side by side, checks: each with its source.Guard: never ranked, never prescribed
05 · مراجعة المختص
Specialist reviewAccept, edit or reject each item, with a reason.Guard: nothing acts without it
06 · توثيق النتيجة
Documented outcomeThe decision, signed, with everything that was shown.Guard: append-only record

What the system never outputs

  • A diagnosis
  • A prescription, a dose or a device setting
  • A ranking of components or options
  • Whether a person is ready for fitting or discharge
  • A sentence without a quote behind it

Checks every answer passes

  • Quote check: the quote is in its passage, word for wordRemoved if not
  • Advice check: no instruction, dose or settingFlagged
  • Population check: the source's own population namedShown
  • Hard stops: the clinic's rules, versionedRoute to a person

Where data goes

  • Search runs on the clinic's server
  • One language model, behind one swap point: a local model, or a cloud one the clinic has approved
  • To a cloud model only coded fields and passages, never typed notes
  • Each domain switched on for the cloud separately, by the owner
