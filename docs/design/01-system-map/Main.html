Roll-out

A proposal; the owner sets the order
  1. Phase 1Knowledge layer, reasoning and review, prosthetics; a trial with a prosthetist
  2. Phase 2Orthotics, once the owner and an orthotist confirm its drafts
  3. Phase 3Smart search and case-based learning, on the same library
  4. Phase 4Patient record, consent and access roles, before any real data
  5. Phase 5Gait analysis and rehabilitation, which need their own data capture

The same rules in every part

  • Supports the decision; never diagnoses, prescribes, chooses or ranks
  • Every AI sentence carries a quote checked word for word
  • Clinical values come only from the owner and the specialists
  • English and Arabic; quotes stay in their source's language
